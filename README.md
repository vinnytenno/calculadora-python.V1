Minha primeira calculadora desenvolvida em Python, criada como projeto de estudo para praticar conceitos básicos de programação e lógica.

## Funcionalidades:

A calculadora pode realizar:

- Adição;
- Subtração;
- Multiplicação;
- Divisão;
- Validação de divisão por zero;
- Validação de operações inválidas.

## Conceitos práticados:

- Variáveis;
- input() e print();
- Conversão de dados com float();
- Estruturas condicionais if, elif e else;
- Operadores matemáticos;
- Operadores de comparação;
- F-String;
- Lógica de programação.

## Execução:

Tenha o Python instalado e execute o arquivo:

calculadora_v1.py
